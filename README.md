# Workforce Management Web App | Frontend Case Study

Case study of a workforce management web application built at **Offneo**, where I worked as a frontend developer in a cross-functional team.

## About the System

Covers employee check-in/out, leave requests, payroll, and location-based attendance tracking.

## My Role

- Built frontend modules using React, Redux Toolkit, and Tailwind CSS
- Integrated REST APIs with the frontend and managed application state
- Contributed basic-level API work alongside the backend team

Core backend logic was handled by the backend team.

## Tech Stack

`React` `Redux Toolkit` `REST API` `Tailwind CSS`

## Note

This application was built at Offneo and is a private product, not publicly deployed. Out of respect for confidentiality, this case study contains no product name, screenshots, or client details.
