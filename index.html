Workforce Management Web App

Frontend case study by Muhammad Dawood Butt, Frontend Developer at Offneo

A web app for day-to-day workforce operations. Attendance, leave, payroll and location-based tracking live in one dashboard for admins and employees.

Built at Offneo. Private product, not publicly accessible.

Built with

  • React
  • Redux Toolkit
  • REST API integration
  • Maps integration
  • Tailwind CSS

What it is

A workforce management system used inside a company's internal operations. Employees check in and out, request leave and view payroll details. Admins monitor attendance and manage the workforce from one operations dashboard. It runs in a live production environment.

My role

I worked as a frontend developer in a cross-functional team, building frontend modules and integrating them with REST APIs. I also worked on the backend side and built some medium-level APIs, while the backend team handled the core backend logic.

  • Built multiple frontend modules as part of a team
  • Component-driven UI shared across modules
  • REST APIs connected to the UI
  • Built medium-level backend APIs alongside the backend team
  • Global UI state managed with Redux Toolkit
  • Responsive layouts for admin and employee views

What's inside

Operations dashboard

Live headcount, presence and leave metrics, attendance trend charts and notifications.

Attendance and leave

Real-time check-in and check-out with location-based validation, and leave requests with an approval flow.

Payroll

Salary breakdown and payslip view, driven by attendance and leave records.

Administration

Account and company settings, plus content management for staff.
